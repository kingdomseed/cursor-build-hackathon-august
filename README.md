# cursor-build-hackathon-august

Hackathon project workspace. Structured Workflow is installed first so later
work can follow the A–D design cycle.

## Structured Workflow

Installed from [kingdomseed/structured-workflow](https://github.com/kingdomseed/structured-workflow)
at `013a919`.

| File | Role |
| --- | --- |
| `AGENTS.md` | Always-loaded workflow rules |
| `workflow-tracker.md` | Current phase, criterion, and next move |
| `GLOSSARY.md` | Shared project language |
| `.cursor/skills/` | 20 phase and criterion skills |

Start a new cycle with `$start-inquire-and-analyze`. The default first
criterion is **A1 — Explain and justify the need**.

Upstream still treats project templates, companion subagents, hooks, and a
packaged installer as unfinished. This repo vendors the published skills and
the durable project files so the cycle can run in Cursor now.
